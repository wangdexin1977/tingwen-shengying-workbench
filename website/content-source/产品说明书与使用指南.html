01 产品定位与阅读方式

听文视频工作台是一款在 Android 手机内独立运行的文字、语音和照片视频制作工具。用户输入朗读文案，选择音色和画面素材，先生成并检查 MP3 与图片，再明确确认素材，最后由手机本机编码生成 1920×1080 MP4。整个流程围绕“文案 → 声音 → 画面 → 预览确认 → 成片”组织，适用于故事朗读、知识讲解、文章配音、照片叙事和静态画面解说。

本文以 Android 正式版 1.0.2 和 独立试用版 1.0.2-trial 为准，业务基础对应 PC 1.5.9。两版采用相同的基本创作流程；试用版额外执行整个试用期间的累计额度。APK 安装后无需连接原 PC 工作台，也无需在手机上另装 Python、FFmpeg 或本机绘图模型。

本说明书面向使用者、培训人员和产品服务方。需要理解代码、部署、接口、安全控制或故障定位时，请阅读同一文件夹中的《技术架构与实现文档》。文档中的“图示示例”用于解释机制；界面截图来自当前版本的浏览器检查，使用测试内容，不包含用户作品。不同 Android 系统的文件选择器、分享菜单和通知权限界面可能不同。

03 安装、首次启动与升级

安装前准备

  1. 确认设备为Android 7.0/API24及以上，CPU支持ARM64；x86_64包内组件也可用于相应设备或模拟器。当前APK不包含32位ARM或x86运行组件。
  2. 下载你需要的正式版或试用版APK，核对版本文件名。需要验证来源时，可对照同一GitHub发布页的SHA256校验和。
  3. 为新语音生成准备可用网络。手机照片导入、画面加工和MP4编码在本机完成，但“本机制作视频”并不表示整个流程完全离线。
  4. 确保有足够存储空间。应用会同时保留任务原文、语音分段、MP3、规范化图片、1080p画面及成片；将成片另存到系统文件夹还会产生一份副本。空间需求随文案时长和照片数量变化，当前没有固定的最低剩余容量提示。

安装步骤

  1. 在系统文件管理器或浏览器中打开APK。
  2. 若系统要求，为正在打开该文件的应用启用“安装未知应用”权限。
  3. 完成安装，点“打开”或从启动器打开应用。
  4. 首次出现约3秒的科技蓝动态启动画面，展示文字、声音、视频之间的转换。服务与页面同时加载；若准备耗时超过3秒，继续显示真实准备状态，不强行进入尚未就绪的页面。
  5. 若提示通知权限，按实际需要允许，以便从通知栏查看后台任务阶段并回到应用。权限请求安排在开场之后；不需要授予全盘照片或文件读取权限才能使用系统选择器。

覆盖升级与数据隔离

同一版本系列沿用原应用包名和签名，安装新APK可覆盖旧正式版或旧试用版并保留应用内数据。不要先卸载再安装来代替升级：卸载或清除应用数据会删除私有任务库。正式版与试用版是两个独立应用，安装正式版不会自动迁移试用版草稿、任务和照片；需要保留的成品应先导出。

当前交付文件：听文视频工作台-Android-v1.0.2.apk 与 听文视频工作台-试用版-v1.0.2.apk。正式版约44,472,826字节，试用版约44,492,954字节，实际安装占用还包括Android运行时展开内容与后续任务文件。

05 从文案到成片的完整工作流

  1. **准备文案。**输入正文或导入文件，检查内容、清洗结果和音色。正式版可以保存超过10000字的文案；试用版应先查看剩余额度。
  2. **决定是否加标题。**填写主副标题或全部留空。输入的是“画面上的字”，正文输入的是“要朗读的内容”，两者各有用途。
  3. **选择画面来源。**手机照片最直接；也可以使用公开图片直链，或在明确同意费用后调用自己的Seedream账户。
  4. **生成素材。**创建任务后启动音频处理；本机照片可立即成为图片素材，URL或AI图片准备可与音频处理并行进行。
  5. **检查素材。**等MP3和图片均准备好，在任务页试听、放大预览、删除不需要的照片或换图。检查的是任务保存的原文，而不是当前另行编辑的草稿。
  6. **明确确认。**点击“确认…张照片，生成MP4”。未确认时不会自动开始视频编码；换图、删图、重生成后需要再次确认。
  7. **本机编码并验证。**手机将图片加工成1080p画面，分配时间轴，编码MP4，检查尺寸、音轨和时长，再将成片标记为完成。
  8. **保存或分享。**从任务或作品页播放视频，另存到你指定的系统目录，或分享给目标应用。

一次照片讲解视频的操作示例

以正式版为例：准备约1000字讲解稿和4张照片 → 主标题填写“6G 通信”，副标题填写“产业协同与应用路径” → 选择云健 → 从手机多选4张照片 → 点击生成素材 → 试听MP3并放大检查照片 → 删除1张不适合的照片 → 确认剩余3张 → 生成后播放MP4 → 保存到系统“下载”或你选择的文件夹。

如果最终配音时长为90秒，3张保留照片各分配约30秒。该数字只是均分规则示例，不是本应用的生成速度或语音速率承诺。第一张叠加标题，第二、第三张保持照片画面；本流程不自动生成字幕。

06 文案输入、导入、清洗和标题

直接输入与实时字数

正文框用于完整朗读内容。字符数按Unicode字符统计，汉字、字母、数字、标点、空格、换行均可贡献计数，不能把界面“字”理解为只数汉字。长文在输入框内滚动，不需要为了避免界面变长而删除正文。新任务创建时正文会去除首尾空白；试用累计输入计数在编辑过程中进行，和最终朗读时去除首尾空白的任务正文口径有区别。

按原稿合理分段有助于朗读。应用会自动将长文拆成每段最多2000字符的语音请求；不需要用户先人工分成多个任务。该分段只服务于语音处理，不建立“文字段落—照片”的一一对应关系。

导入TXT／MD

  1. 点“导入TXT/MD”，从Android系统文件选择器选择文档。
  2. 文件内容载入当前正文框，核对编码、标点及是否完整。
  3. .md文件导入会移除代码块、标题前缀、Markdown图片、链接地址及部分格式标记，保留链接可读文本；这是一组固定格式处理，不是AI改写或语义摘要。
  4. 若字符显示乱码，可先把原文另存为UTF-8 TXT再导入。当前接口没有提供编码手动切换，也不直接读取Word、PDF或扫描件。

导入会替换当前正文。正式版可重新导入；试用版将按内容新增／替换规则记入累计输入，删除后重新输入不会退还旧用量。试用前宜在其他编辑器中整理好正文，再导入最终版本。

文案清洗与撤销清洗

“文案清洗”用于整理适合朗读的正文，包括Markdown格式、HTML标签、链接与图片、列表或标题符号、括号外壳以及部分格式化空白等；保留括号内文字、数字和通常的标点，数字之间的星号可转换为“乘以”。它不会自动解码&amp;、&nbsp;等HTML实体。它会改变当前编辑框，移除裸网址、图片语法和代码围栏等；代码围栏内的正文在显式清洗时保留，而MD导入会移除整个代码块，两者并非同一规则。清洗不会自动改写观点、补充内容或生成新文章。完成后查看清洗状态、前后字数以及具体结果。

“撤销清洗”恢复最近一次有效清洗前保留的原文，是清洗专用回退入口，并非完整多步编辑历史。清洗后手动编辑正文会禁用这一撤销，清空工作区或重新启动也不保留临时撤销缓存。正文变化不改动已经创建任务的MP3；要让修改后的正文生效，应创建新任务。试用版同样对清洗和撤销产生的新增字符进行计数，纯删除不退款，撤销恢复的字符可能新增扣额。

成片文件名与画面标题

MP4文件名始终使用实际任务正文开头30个字符，并替换路径分隔符、控制字符等不合法文件名字符；如果结果为空，则使用“听文视频.mp4”。画面主标题与文件名彼此独立。因此两篇正文开头相同的作品可能显示同样文件名，但应用内部按独立任务UUID目录保存，不相互覆盖；导出到同一系统文件夹时，应按系统提示选择保留方式或自行改名。

07 26种音色、试听与音频合成

应用默认音色是云健，已有安全偏好会恢复上次所选音色。点击“更换音色”展开列表，点选后立即播放随APK提供的样音，选中音色显示在摘要区域。仅在点选试听时播放；恢复偏好不自动播放。音色名称与描述是当前产品提供的选择信息，不表示针对每段文案的音质保证。

音频处理过程与进度

  1. 创建任务时固定正文和所选音色。
  2. 正文按段落和2000字符上限拆分；过长段落按长度继续切分。
  3. 按顺序逐段联网获取MP3数据。每段先写入临时文件，只有收到非空且可探测的音频才保存为完成分段。
  4. 网络中断或超时，每段最多自动重试2次，即首次请求加最多2次重试；两次退避等待分别为1.5秒和3秒。
  5. 每段成功后更新“已完成段数/总段数”。所有片段就绪后合并并验证，生成最终audio.mp3。

任务页百分比首先反映完成分段数量，不是按声波字节或精确时间比例计算的预测进度；合并和验证阶段可显示不定百分比。网络等待时会提示本次等待秒数和已接收数据量。通知栏展示处理阶段汇总，不承担任务页的详细百分比展示。

失败、重试与保存

若某一段失败，可检查网络后点“重试音频”。已经成功落盘的分段会复用，不必从头请求全部文案。取消会保留已完成素材，未完成临时片段不会被当成成功音频。MP3达到“完成/可试听”状态后可以单独保存或分享；即使尚未确认视频，也能交付配音。

本版本没有向用户开放语速、音量、音调、SSML编辑、声音克隆或自定义音色训练控件；界面中的“26音色”是固定列表，不能据此推断支持本机大模型语音生成。

08 三种画面来源与照片管理

手机照片

  1. 图片方式选“手机照片”，点选照片进入系统选择器。
  2. 支持多选，但系统照片选择器自身可能设更小的多选上限，50张是本应用的上限，不保证每台设备一次可选50张。选择完成后，在预览区核对顺序、文件名、张数和总大小；可点图片打开大图。
  3. 删除不需要的预选照片，再点击生成素材。当前选择批次用于新任务，重新选取一批不会自动追加到旧的未提交批次。
  4. 任务保存后，在任务页删除不需要的照片时至少保留1张；当前没有拖拽排序界面。成片遵循导入/保留顺序，不按传入索引数组任意重排。

每批最多50张，单张20MiB，合计40MiB；试用版还叠加累计10张规则。文件大小保护按原文件计算，传到本机接口的Base64会比原文件更大，所以请求体仍可能触发64MiB保护。超出技术保护时先减少张数或压缩图片；正式版没有累计试用扣额。

支持JPEG、PNG、WebP、GIF、BMP和TIFF等常见格式；动图、多帧图以第一帧作为静态照片。导入处理拍摄方向，透明图使用白底，转换为可用的RGB PNG并清除EXIF等元数据。HEIC/HEIF、AVIF依赖Android系统解码能力，不能仅凭文件后缀保证任意设备均可读取；失败时可先转换成JPEG/PNG。照片像素数另有5000万像素、单边16384像素保护。

网上图片网址

使用公开图片文件本身的HTTP/HTTPS直链，填入“网上图片网址”后生成素材；不能用新闻网页、公众号文章页面、登录链接、网盘展示页或带账号密码的URL来代替图片直链。应用检查公网地址、目标端口、重定向和响应格式，拒绝局域网、回环地址及不符合安全要求的目标。

如果图片网站禁止外部访问、要求Cookie/登录或临时签名已过期，下载可能失败。可以通过你已有访问权限的浏览器先保存图片，再从手机照片导入。应用不会绕过登录或验证码，也没有从文章页提取多图的用户入口。不要把“图片网址”理解成“网页内容转视频”。

AI生成图片：豆包Seedream

  1. 图片方式选“AI生成图片”，填写场景、构图、主体、色彩等图片要求。
  2. 选择图片来源“豆包Seedream·云端收费”。Android版不提供电脑本机Draw Things入口。
  3. 模型可选当前打包的doubao-seedream-5-0-pro-260628（默认）或doubao-seedream-5-0-flash-260915。该列表是APK配置，不代表服务端未来一定保留访问权限。
  4. 填写自己的火山方舟API Key，勾选明确的付费同意，再创建任务。
  5. 当前请求设置为2K、单张PNG、保留AI水印；最终视频仍加工成1920×1080。生成时间和费用由服务端及账户实际情况决定。

API Key只在运行内存中使用，不写入草稿、任务JSON或自动日志；进程完全关闭后需重新填写。模型选择和付费勾选也不在草稿保存字段内，重新打开可能回到默认Pro并需要重新勾选。图片要求会发送给云端服务。首次生成、手动重试或重新生成都可能产生新的收费请求；不存在“重试永久免费”的保证。

画面适配

横图和竖图都先加工成1920×1080画面。完整照片按比例缩放居中，空余部分用原图拉伸并模糊的背景铺满；因此主体前景不会为了填满横屏而被任意裁掉。产品没有让用户手动选“裁切／拉伸／模糊填充”的切换按钮。

09 任务页：检查、确认与状态理解

查看任务保存内容

任务页显示选中任务的标题、模式、语音/配图/视频三个阶段。“查看本任务保存的文案与图片要求”可以展开核对正文和提示词。新任务创建后这些内容成为任务快照；你在创作页编辑的是另一个草稿，不会偷偷修改当前任务的音轨或标题。

确认素材的正确顺序

  1. 确认MP3已完成，播放一段并检查读音、内容完整性与音色。
  2. 确认图片已完成；检查单图显示，多图核对数量、顺序、是否至少保留1张。预选照片卡与任务多图卡可点击放大；任务单图没有单独放大入口，必要时保存首图到系统位置再查看。
  3. 如有不满意的画面，先换图或重生成；处理完成后重新检查。
  4. 确认任务没有暂停/取消，其他步骤已结束。
  5. 点“确认…张照片，生成MP4”。应用记录当前照片版本和内容摘要，并在实际编码前再次核对。

任务页展示的图片是当前原素材，主副标题在合成画面阶段才制作，因此原图片预览不等同于最终标题版式预览。如果收到“图片版本已改变，请重新预览确认”或“确认后的图片发生变化”，重新载入任务并检查当前图片，不要用旧页面的确认按钮强行继续。该提示是防止旧照片与新确认错配的保护，不能通过只修改创作页提示词来消除。

10 MP4合成、播放与结果检查

确认后，应用依序制作1080p画面、生成图片时间轴、编码视频、检查媒体规格，最后把临时文件发布为任务成片。视频和配音的总时长匹配，多张照片按保留数量平均分配音频时长；第一张显示标题，后续照片不带标题，没有自动字幕、背景音乐或转场。

任务页进度分为“画面准备”“视频编码”“验证画面与音轨”“MP4已完成”。编码百分比根据FFmpeg实际输出时间与音频时长计算，验证完成前最高显示99%；不按固定秒数假装进度。耗时随手机CPU、散热、文案长度、照片数及后台限制变化，本版本没有提供固定出片时间承诺。

交付前检查清单

  • 播放开头：主副标题是否正确，留空时是否没有多余标题。
  • 播放中段：画面是否按保留顺序切换，声音是否持续，竖图是否完整。
  • 播放结尾：朗读是否覆盖正文结尾，是否有明显提前结束或异常长尾。
  • 核对文件：MP4可播放并含音轨，文件名与正文开头对应；需要另一种命名时在系统保存界面修改。
  • 完成另存：确认目标系统文件夹中实际存在文件，再执行卸载或清理应用数据。

本机自动检查覆盖1920×1080、存在视频/音频流、时长差阈值等规格，不等同于人工审核每句内容和每个字形。关键成品仍应由使用者试听和观看。

12 暂停、继续、取消、后台与恢复

暂停和继续

“暂停”设置本机任务的暂停标记。语音网络等待与文件合并会在检查点等待；视频编码通过暂停整个编码进程组停止前进。“继续”解除暂停，保留已有进度。图片请求如果已经送达云端，不能靠本机暂停让服务端停止计费，应用也无法提供云端百分比。

取消与重试

“取消”让后续处理停止，保留已完成MP3分段、图片和实际成片。取消网络等待、本机画面或编码过程需要步骤响应控制信号；“正在取消”不等于已经完全停止。尚未结束时，不要连续创建另一个任务或立即重试同一步骤；等界面允许操作再继续。

“重试音频”使用任务固定正文和音色，复用完成分段。“重试图片”用于AI任务，依当前模型配置执行，Seedream需要重新具备有效Key和费用同意；网址或手机照片失败需重新填写网址或选择照片。“再次确认”用于视频失败后的制作恢复，不会自动重做已准备素材。

返回、锁屏与强行停止

正常返回桌面或锁屏，前台服务继续承载任务，通知显示处理阶段。Android返回键通常先从任务/作品/关于回创作，音色列表展开时先收起，再进行页面后退或退出。省电模式、厂商后台清理、网络断开、存储不足或系统回收仍可能使任务中断；前台服务不是永不退出的保证。试用版在真正返回退出时等待输入队列及草稿保存落盘，避免刚输入的字数或草稿丢失。

“强行停止”或系统杀进程后，重新打开应用会保留已生成素材，把原先等待/处理中步骤标记为待恢复，而不是假装仍在运行。选择对应历史任务，查看哪个步骤未完成，再手动重试。“继续”只解除暂停/取消标记，并不自动重启已经取消或中断的步骤；分别使用“重试音频”、重新选择照片/网址、图片重试或“重试合成”。进程重启不会自动重新提交Seedream收费请求。

同时处理限制

应用为避免素材错配和设备资源竞争，会拒绝在已有活动任务时创建另一任务；同一个任务的音频与图片准备可并行。换图和删图也受活动步骤保护，不支持任意多任务并发、批量排队或批量自动生成成片。

13 作品列表、保存和系统分享

作品页列出任务目录内实际完成且非空的MP4，按修改时间排序，显示文件名、大小、时间和任务关联。换图导致任务状态改变时，保留的视频仍可通过作品列表播放。点击刷新重新扫描文件；当前没有删除历史任务、清理素材或批量导出全部作品的按钮。

保存MP3、MP4和图片

  1. 在任务页选择“保存MP3”“保存MP4”或“保存首张图片”；也可在作品列表保存对应MP4。
  2. 系统打开“创建文档”界面，选择目标位置，核对文件名并保存。
  3. 应用将已经完成的文件复制到你选择的目标URI，原文件继续保存在应用私有目录。
  4. 到目标位置检查文件是否完整；如果选择云端文档提供方，后续上传或同步由该系统提供方处理。

MP3/图片导出的建议名称通常参考任务画面标题，标题留空时使用“听文视频”；MP4使用正文开头命名。任务页对外提供保存首张图片的便捷入口，不是自动把整套原始照片备份到公共相册。

分享

任务页可分享MP3或MP4，作品页仅分享MP4，由Android系统列出已安装接收应用。工作台发放只读内容URI权限；接收应用是否支持该MIME类型、文件大小及完整读取由其自身决定。当前分享令牌没有固定到期时长，不应理解为分享后若干分钟自动销毁文件。分享失败时可先保存到系统目录，再从接收应用选择文件。

应用内部路径显示用于说明文件归属，不代表其他文件管理器能直接读取私有目录。要把作品交给别人，使用系统保存或分享，而不是复制界面中的内部绝对路径。

14 草稿、偏好、日志和关于菜单

自动草稿与清空

草稿保存在本机，包括正文、主副标题、图片要求、音色、图片方式、安全的图片来源偏好以及选中任务标识。恢复草稿不会播放样音。API Key、模型选择、付费同意、图片网址和尚未提交的系统文件选择不作为草稿长期保存，进程关闭后需要重新提供这些信息；已创建任务自身会保存模型快照。

顶部“清空”清除当前输入、临时选图和当前任务显示；历史任务、成片、日志继续保留，正在后台运行的任务不会因这一按钮取消。清空后可以从历史任务重新选择。试用计数已发生时不会因为清空退还额度。

运行日志与版本记录

“日志”区域可查看全部运行记录、模型调度记录、历史版本说明，支持刷新、继续加载分页和导出JSON。自动记录包含事件、时间、版本、任务标识、阶段、来源/模型、耗时、状态及照片数量等安全字段；不记录API Key、完整朗读正文、完整提示词或远程图片网址。

任务JSON仍保存必要的正文和提示词，这是作品生成资料，不应把“日志脱敏”解释成“整个应用没有保存正文”。记录文件仅在手机私有目录；导出JSON是用户主动行为，不会自动发送给GitHub或其他服务。历史版本说明是整理记录，和当时实际生成的运行事件有不同含义。

关于菜单

关于页包括当前APK版本、主要功能、音频合成费用说明、联网和隐私说明、核心技术、六步使用方法，以及相关服务说明入口。1.0.2“本次更新”说明6G示例标题与紧凑首页；原约3秒开场与关于功能继续保留。试用关于页补充累计额度、到期规则和微信联系信息。

15 累计试用规则与购买联系

试用额度按整个试用过程累计。不是每个任务10000字，也不是每个任务10张照片。任一额度达到上限，即立即结束制作功能。

文案如何累计

操作 计数方式
第一次输入1000字符 已用1000、剩余9000
在后面追加500字符 新增500，已用1500
保存相同草稿，或同一文案提交任务 不因重复保存/提交重复扣同一已记输入
从原文删除300字符 不增加，但已用额度不减少
替换一段正文 替换后新增的部分计数；不是仅算当前总长度增长
清空再输入或重新导入 清空不退款，后续新增输入继续累计
输入标点、空格、换行、英文、emoji 按Unicode字符口径；不是只数中文汉字，某些视觉字符由多个Unicode码点组成
中文输入法拼音候选 未确认的预编辑过程不扣；确认后的实际内容计数
恢复已有草稿、纯查看历史任务 不因正常恢复或查看再次计数
清洗与撤销 纯删除不退款；恢复或替换出新增内容可能继续计数

这里的“1000字”以产品的Unicode字符口径为准。累计算法比较已接受正文与新正文的新增/替换内容，因此“把1000字改为另1000字”不等于免费修改，也不一定只增加最终长度之差。标题与图片提示词不作为本项朗读正文额度扣除；它们仍受各自规则与请求体保护。正常MD导入按去格式后的正文计数；若原始导入文本本身超过10000字符，会先触发超限结束，不靠去格式绕过。

照片如何累计

新选的手机照片在预选阶段即记账，不需要等生成任务。删掉预选照片或取消任务不返还张数；重新从系统选择器新选同样照片仍是一轮新选择。把已记账的同一批照片直接提交任务，不会再扣一次；删除部分预选照片后提交合法子集，也不会再扣这一子集。

任务中的换图、公开图片网址的新选择以及AI新配图请求都纳入新图片额度。现有图库中的删除/保留筛选不属于新图，不增加也不退款。网址配图在网址/DNS校验前扣1，AI新图在配置、Key和费用同意校验前扣1，因此尚未联网的无效网址、缺少AI认证或最终失败，也可能消耗照片额度。常规不超过10张的手机照片批次在完整解码校验后才扣，解码失败不扣；单批超过10张会在解码前令试用到期。没有根据最终是否成片返还次数的机制。新建任务请求即使最终因已有活动任务而被拒绝，也可能已完成额度记账。

精确边界与立即停止

例如：此前已用9000字符，再新增1000字符，累计到10000时立即到期；此前已选9张，再选第10张时立即到期。第10张可以完成有效选择和记账，但不能再据此启动新的作品；正在进行的音频/图片/视频步骤也会收到取消信号。超出剩余额度的批次或输入会被拒绝并结束试用，不会当成下一任务的可用额度。

到期后可继续查看说明、联系信息和已经完成作品，并导出保留的成品。停止制作包含新任务、继续制作、重试、换图、AI重生成与确认编码等入口。已提交云端付费请求无法由本机额度锁定撤销，其可能返回的素材会按既有保存策略处理。

联系正式版与现有弹窗

联系微信：wzqy2019。到期弹窗提示添加该微信咨询长期使用；关于页也有复制联系信息入口。首次成功完成试用视频后的联系提示是一次性购买咨询提示，不代表额度已经耗尽；真正试用结束由累计阈值或账本安全状态决定。本版本没有内置支付、微信自动添加好友、激活码校验或远程授权平台。

计数保存、旧版迁移与限制

额度账本保存在应用私有目录，跨普通退出和重启保留；损坏或无法可信重建时采取停止制作的保护。旧1.0.1试用版升级时，会根据仍存在的任务、草稿、照片文件和安全事件记录进行保守迁移；旧版未记录且已经删除的输入无法完整重建，不能保证还原全部过去编辑动作。

当前为本机计数方案，卸载、清除应用数据或在另一台设备新装会失去原私有账本，没有跨设备账户累计，也没有服务端防重置授权。正式版和试用版安装数据独立，购买咨询不能自动把试用版解锁为正式版。
