粘贴文案 → MP3 + 自选照片或 Draw Things / 豆包 Seedream 配图 → 用户确认 → MP4。

当前版本记住配图方式与 AI 来源；音色选择后收起，长文框内滚动；刷新仅清空工作区，MP4 文件入口常驻。文章网址提炼功能已撤下，历史多图任务仍可使用。

开发与版本日志见 [CHANGELOG.md](CHANGELOG.md)。运行日志仍仅保存在本机，不上传 GitHub。

## 1.5.1：GitHub 与桌面蓝色启动器

新增原生 macOS 启动器：桌面“听文视频工作台.app”使用蓝色音波 + 播放图标。双击时检测本机 8091 服务；已运行则直接打开网页，未运行则启动服务后打开网页。启动失败显示可见提示，不会停止或重配占用 8091 的其他程序；不会修改原 MP3 转换器、视频首页生成器或 IndexTTS。

桌面入口指向本机源码目录，不是完全内嵌 Python/FFmpeg 的可移植安装包。源码文件夹和 .venv 必须保留。移动源码后请重新安装入口；安装脚本遇到同名桌面应用时不会覆盖，先为旧入口改名再安装。

仓库仅保存代码、依赖清单、测试、26 个本地试听片段和可重建启动器源代码。jobs、web_imports、records、.venv、运行日志、个人电脑路径配置、密钥、含个人任务内容的调试截图均不提交。初次 Git 提交是本次发布快照，不伪造旧版本 Git 提交历史；产品内仍有整理后的版本变更记录。

另一台 Mac 从源码安装（需先安装 Homebrew 与 Apple Command Line Tools，创建环境时使用 Python 3.11+）：

```sh
git clone https://github.com/wangdexin1977/tingwen-video-workbench.git
cd tingwen-video-workbench
brew install python@3.11 ffmpeg
python3.11 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
/bin/zsh 构建启动器.command
```

仓库若为私有，克隆需要当前账号权限（例如先完成 `gh auth login`）。构建使用本机 Swift/AppKit，生成当前 CPU 架构的启动器与 .icns 图标，并在本机 ad-hoc 签名；不上传生成的签名和个人源码绝对路径配置。没有 Apple Command Line Tools 时先运行 `xcode-select --install` 并完成系统安装。可只使用 `启动听文视频工作台.command`，无需构建图形启动器。

## 1.6.11：修复小文件导入 413 与 500 MB 音频上限

上一版照片以 Base64 放入 metadata 表单字段，而 Flask／Werkzeug 默认非文件表单字段上限为 500000 字节，导致约 2.4 MB 的普通照片也返回 413。现仅在已有音频导入接口把表单字段上限设为 64 MB，覆盖最大 40 MB 照片的约 54 MB 编码数据；其他接口限制不变。

单个已有音频上限统一为 500 MB（500×1024×1024 字节），前后端均检查；照片仍为单张 20 MB、每批 40 MB。HTTP 导入请求上限为 560 MB，用于容纳音频、照片编码及表单开销，并不是单个文件可超过 500 MB。实际音频文件按读取到的字节数检查，不依赖文件声明的大小。

## 1.6.10：已有音频和照片直接制作 MP4

右侧“检查素材，确认成片”中展开“使用已有音频制作 MP4”，选择本机音频和一张／多张照片，点击“载入音频和照片，准备生成 MP4”；音频验证完成后，点击“确认照片，生成 MP4”。不需要先使用本程序生成 MP3，不调用微软语音、OmniVoice 或图片模型。

支持 MP3、WAV、M4A、AAC、FLAC、OGG、AIFF、OPUS、WMA，单个音频最多 500 MB；照片沿用每批最多 50 张、单张 20 MB、合计 40 MB 的规则。浏览器用文件表单上传至本机服务，导入接口请求上限 560 MB，原有 JSON 接口仍为 64 MB。程序完整解码并转换为 192 kb/s 的标准 MP3 供当前流程使用，原始音频按原字节另存为任务目录里的 `source-audio.<扩展名>`；不覆盖用户选择的源文件。导入过程可暂停、取消和重试，重试只处理已保存原文件，不会改为调用语音模型。

文案可以为空，视频覆盖完整音频时长，多张照片平均播放；标题与背景音乐使用当前设置。没有对应文案时关闭口播字幕；需要字幕时，可在载入前在左侧填写与音频一致的文案，并开启字幕，字幕按完整音频时长估算同步。没有文案时，MP4 以原音频文件名主体命名；有文案仍按文案前 30 字命名。

“版本与日志”已更新 1.6.10 发布记录；音频导入归入本机处理，完成时额外记录音频时长和原文件字节数，不列为模型调用，不记录原文件名、原电脑路径或文案。

验证：`./.venv/bin/python -B -m unittest test_audio_import -v`，真实 MP3／WAV／M4A 导入、无文案 MP4、背景音乐、估算字幕、原文件保留、无语音模型调用、格式／损坏／大小校验与重试。

## 1.6.8：微软在线合成接口兼容

微软在线语音在旧合成地址持续返回 403，而当前 Edge 使用 `api.msedgeservices.com/tts/cognitiveservices/websocket/v1`。本工作台针对仍使用旧地址的 edge-tts 7.2.8 增加进程内兼容补丁，迁移到该微软接口，继续使用原音色、MP3 格式及词级时间信息。保持正常 TLS 证书校验，不使用第三方转发、不修改 site-packages。上游库若已经迁移接口，补丁不会覆盖其实现；语音列表仍沿用库原实现。

HTTP 日期改用不依赖系统语言的解析器，兼容 GMT 和数字时区，便于校时重试。保留原分段、取消、暂停、超时与已完成片段复用；不会自动切换到 OmniVoice。失败任务可直接点击“重试微软音色”。参考上游 [edge-tts PR #491](https://github.com/rany2/edge-tts/pull/491)，此时仍未进入 PyPI 正式发布，本工作台采用经本机验证的窄范围兼容改动。依赖最低版本调整为 edge-tts 7.2.8。

## 操作流程

1. 填写标题与朗读文案，支持直接粘贴和 UTF-8 TXT/MD 导入，不设字符数上限（请求仍有 64 MiB 技术保护）。
2. 点击“更换音色”展开并列卡片，选中即试听并自动收起；首次默认第一个“云健”。点击使用本地 MP3 试听，并在当前浏览器记住所选音色，下次打开自动恢复，不自动播放；无记录或记录失效时回到“云健”。清除浏览器数据、换浏览器不共享此记忆。语音接口未传音色时也默认“云健”。
3. 填写图片内容、风格、光线。本地模型的中文能力取决于模型，Stable Diffusion v1.5 建议英文描述；程序不会擅自使用其他云端翻译服务。
4. 选择 Draw Things 或豆包。Draw Things 先点击“检查本地连接”，显示应用当前选中的模型；生成请求固定单张 768×512，并保存模型、步数、采样器、引导强度快照。豆包默认 doubao-seedream-5-0-pro-260628，2K、AI 水印；也保留 doubao-seedream-5-0-flash-260915。
5. 点击生成 MP3 和配图，音频与图片并行生成。仅豆包需要付费确认；本地失败不会自动回退到豆包。
6. 图片预览下方默认折叠“更换照片或重新生成图片（可选）”，展开后可更换照片或调整图片要求。可沿用原要求再生成一张，也可以修改要求；保留 MP3、保留旧图、清除确认状态，新图需要再次确认后才生成 MP4。生成时按钮禁用，并拦截快速重复点击。豆包仍需付费同意，不会自动切换来源。已有失败任务也可展开“需要更换图片来源或模型？”，点击“使用左侧所选来源生成”，明确切换到新来源；左侧选择本身不会修改已有任务。重试和重新生成沿用任务原模型与参数，更换来源才读取新配置。
7. 确认当前图片版本及标题／字幕设置后，才开始本机合成 MP4。1920×1080 横屏，口播字幕按当前设置写入画面，单张图片覆盖完整音频；统一视频标题最多 30 字（换行不计），默认暖黄色大号粗体，无背景底板，可自选字体、字号和颜色。支持手动／自动分行，按实际字形缩放，不重叠。只有首页叠标题，后续照片不变；标题为空不加文字。图片以 fit-blur 适配。
8. 下载 MP3、PNG、MP4 或打开独立任务文件夹。MP3 和 MP4 各自下方显示完整保存路径，分别点击“打开 MP3 所在文件夹”“打开 MP4 所在文件夹”，Finder 会打开并选中对应文件。历史任务同样可用；文件未完成时不显示入口。下载按钮是浏览器下载的副本，页面路径指向工作台原始文件。UUID 隔离任务，不覆盖其他素材。

新生成 MP4 的实际文件名与下载名：统一使用朗读文案开头 30 个字符，不足 30 字则使用全文；画面标题不参与文件命名。文件名非法字符替换为下划线；每个任务在独立 UUID 目录中。历史任务的现有文件不自动改名，仍可播放、下载和定位。

1.4 配色参考本机“IndexTTS 2.5 专业语音工作台”：#eef3f8 灰蓝底、白色面板、#182235 深蓝文字，标题栏 #0757d9 → #0788ee → #00aeea 蓝青渐变，主按钮 #1d4ed8 → #2563eb 蓝色渐变。选中音色为浅蓝高亮；暂停黄、取消红。仅参考颜色，不改动 IndexTTS 应用。

## 自选本机／网上照片（1.3）

- 新任务在“配图方式”中选择“选择本机照片”或“粘贴网上图片网址”，再生成 MP3。不需要图片提示词、Draw Things 或豆包 API Key，不调用图片模型。
- 已有任务在图片下方直接选择本机文件即可替换，或粘贴图片直接网址并点击“使用这个网址的照片”。MP3 和旧图保留；显示新图后需要重新确认才能合成 MP4。失败任务也可选自己的照片继续制作。
- 支持 JPEG、PNG、WebP、HEIC/HEIF、AVIF、BMP、TIFF、GIF；单张 20 MB、5000 万像素、单边 16384 像素以内。动图取第一帧，透明区域铺白色，处理拍摄方向并移除 EXIF 元数据，统一保存 PNG。
- 网上照片需要公开 HTTP/HTTPS 图片网址（80/443 端口），不支持登录、网页链接或防盗链绕过。无法下载时请先保存照片再选择本机文件。下载失败不会破坏当前照片／视频确认。
- 服务端验证所有 DNS 地址及跳转目标，只连接已验证公共 IP，并正常验证 HTTPS 证书；禁止本机／局域网／保留地址、HTTPS 降级、账号密码网址，最多三次跳转。不发送 API Key、网站 Cookie 或账号凭据，也不保存带参数的原始图片网址。
- 原有 AI 生图、直接重新生成图片、更换图片来源和付费确认均保留。自选照片不会隐式触发 AI 生成。

## 暂停、取消、失败与恢复

- 暂停本机语音读取和视频进程组；未提交的图片请求等待继续。已发给 Draw Things 或豆包的请求无法通过工作台暂停或取消撤销，可能继续生成；豆包可能继续计费。
- 已提交后即使点击取消，仍尽量接收并保存返回的收费图片；停止后续处理，不自动合成。等取消结束可点“继续”，保留素材。
- 超时、服务器异常或返回无效图片，可能存在已计费但未收到图片的情况。程序不自动重试收费 POST；手动重发需再次确认可能重复扣费，请先检查方舟用量。
- 重启只恢复任务记录，不自动调用外部服务。MP3 已完成的分段与收费提交状态保留。
- 旧 AI Horde 任务保留查看、下载、音频恢复和已有素材本地合成，不再请求 AI Horde。需要新图时明确更换来源。horde.py 仅保留为旧实现参考，当前应用不导入、不调用。
- 同时仅一个任务生成，重复确认不重复合成；图片版本与内容摘要用于确认锁定。
