# 虚拟新闻男主播

news-anchor-male.png 是本项目通过 imagegen 内置工具于 2026-10-21 生成的虚构男性形象，保留透明通道。没有采用真实主播的照片。

生成要求：原创虚构中国男性，约 40 岁，正面直视镜头，短黑发，无胡须，无眼镜，沉稳自然，静止时轻闭嘴；深蓝西装、白衬衣、暗红领带、领夹麦；半身构图，完整头发和双肩，均匀正面柔光，清晰嘴部，真实皮肤，透明背景，无文字标志和桌面。用于普通话新闻音频驱动的人物口型。

JSON 中的 face_box 是此固定素材的人脸裁剪坐标，不适用于其他图片。更换形象时必须重新校准裁剪，并重新验证口型。

news-anchor-male-blink.png 由同一内置工具基于原图编辑：仅轻闭双眼，保持头部、眉毛、鼻嘴、服装、姿势和透明背景对齐。视频只在短暂眨眼时使用两处眼睑区域，不把闭眼帧用于嘴部动画。

口型模型及其依赖遵循各自授权；本目录不包含模型权重。安装环境、下载缓存和测试成片不上传 GitHub。

完整的原始生成及编辑提示词、工具方式和素材文件名见 [prompts.json](prompts.json)。
