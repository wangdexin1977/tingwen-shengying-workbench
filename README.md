# 听文声影工作台 1.1.0

独立整合听文视频工作台 PC 1.6.11 与本机 IndexTTS 工作台 0.5.10。两种创作模式共用完整流程：稿件整理与清洗 → 选择音色 → 合成 MP3 → 配图、标题、字幕与背景音乐 → 确认生成 MP4。

## 启动

双击桌面“听文声影工作台.app”，或者本目录的“启动听文声影工作台.command”。打开 http://127.0.0.1:8092/ 。专业朗读工作区由界面按需启动，使用 7862 端口。

这是一份本机独立应用，任务、音色库、配置、文档与日志分别保存。为了避免复制大量已安装模型和依赖，复用现有 Python 环境、模型权重及语音运行库；不能删除原 Python 环境或移动权重目录。本机入口不是包含全部模型、正式签名与公证的可迁移安装包。不会修改或停止 8091 的听文工作台与 7860 的原 IndexTTS。

## 使用

1. 选择短视频或长篇朗读。两者默认都制作完整 MP4；“仅生成 MP3”是可选操作。长篇视频同样支持配图、标题、字幕、背景音乐与全部视频设置。
2. 粘贴稿件或导入 TXT、MD、DOC、DOCX、PDF、EPUB、MOBI。主工作区支持多文档排序、章节勾选、每本书全部选中/全部取消选中与整合，之后可编辑、清洗及撤销清洗。格式解析与 OCR 沿用原 IndexTTS；Markdown/TXT 原解析器可能作为整篇章节显示。主工作区文档上限 40 MB，原专业工作区仍支持原有大文档导入。
3. 选择微软在线语音或本机克隆语音。本机六种语音后端保留，使用独立复制的 140 个音色，可试听、查找和添加。常用语速、分段停顿可直接调整，种子、采样与模型参数展开调整。各模型只在已安装完整权重时可生成，保留原来的缺失权重提示，不自动下载。
4. 选择本机照片、公开图片网址，或 Draw Things / 豆包生成配图。图片顺序、删除、重生成和替换均保留。单图覆盖完整音频，多图按顺序平均分配时长。收费图片请求仍需在界面明确同意。
5. 首页标题和背景音乐首次默认关闭；用户主动开启后保存并在下次恢复。生成后试听 MP3、检查照片，在右侧选择音乐与字幕开关，确认后生成 MP4。标题字体、颜色、字号、字幕细调与音乐导入等完整参数保留。背景音乐开启后的初始参数为 15% 音量、3 分钟循环，可改为 2 / 5 分钟或关闭；音乐写入 MP4，MP3 保留纯朗读。
6. “成品文件 · MP3 / MP4”在标题栏常驻，可播放、下载、查看完整保存路径与在 Finder 中定位。当前结果区也分别提供 MP3 与 MP4 的定位入口。专业工作区生成的音频，包括自选输出目录的音频，可在成品库继续送入视频流程。
7. MP4 旁边的“发布到今日头条”打开系统默认浏览器中的官方视频发布页，同时在 Finder 中选中 MP4。选择或拖入视频，填写标题和简介并在头条确认发布；提供标题复制。首次需要登录。应用不读取平台登录凭据、不代替用户点击最终发布，不声称已自动上传视频。

视频画面标题与 MP3 / MP4 文件名默认取文案前 30 个字符，连续空白归一化，不足 30 字用全文。文件名非法字符替换为下划线。可修改画面标题或关闭首页标题；文件命名仍取文案开头。每项任务使用独立 UUID 目录；专业音频同名时追加序号。已有任务保持原来的文件名。

## 完整原功能保留

| 功能 | 统一工作区 | 专业朗读工作区 |
| --- | --- | --- |
| 稿件导入、清洗、整合与撤销 | 支持 | 支持原文档与清洗功能 |
| 书籍章节选择、文档队列确认/排序/批量生成 | 导入、勾选、排序、整合 | 完整原功能 |
| 六种语音模型与克隆音色 | 支持克隆主流程 | 完整模型参数、自动/设计音色等原功能 |
| 音色上传、试听、收藏、删除与模型专用参考原文 | 上传、试听、查找 | 完整原功能；删除沿用可恢复音色垃圾箱 |
| 多人轮流朗读、实时播放、输出目录与 WAV / MP3 / FLAC | 可接收成品继续制作 MP4 | 完整原功能 |
| AI 配图、自选图、网址图、多图筛选与重新生成 | 完整保留 | 生成音频后交接 |
| 已有音频直接制作 MP4 | 完整保留 | 成品一键送回主工作区 |
| 首页标题、实时样式预览、字幕与音乐 | 完整保留 | 交接后使用相同功能 |
| 暂停、继续、取消、重试、素材保留、记录与日志 | 完整保留 | 完整原功能 |
| MP3 / MP4 成品入口、完整路径与 Finder 定位 | 统一成品库 | 成品自动登记与交接 |

本机单次朗读保留原 IndexTTS 的 100000 有效字符上限和 2500 字长文分批。更长书籍可在专业文档队列分卷制作。主工作区与专业工作区的模型生成使用进程间互斥锁；生成完成释放模型，避免两个工作区同时占用大量统一内存。本机生成期间使用防自动休眠；暂停、终止与重试沿用既有行为。重启标记未完成任务为中断，不自动重发收费请求。重试不保证从每种模型的已完成片段精确接续；已有音频片段保留供检查。

语音字幕沿用原功能：微软在线语音有可用词时间信息时按实际时间同步；本机克隆或导入音频按时长估算同步。关闭字幕仍可生成完整长视频。

## 数据位置

- `jobs/<UUID>/`：每个项目的文案、照片、音频、视频与生成诊断。
- `tts/outputs/webui/voices/`：独立音色库，使用文件系统副本，不链接原音色文件。
- `tts/outputs/webui/user_settings.json`：专业语音设置。
- `tts/outputs/webui/products.jsonl`：专业成品登记，保留自选输出目录入口。
- `documents/`：导入文档与解析缓存。
- `records/`：本应用运行日志；原软件运行日志不迁入。
- `settings/preferences.json`：主工作区完整参数快照；同时缓存于浏览器。参数修改后自动保存，顶部显示保存状态，也可点击“保存配置”。
- 浏览器当前来源的独立命名空间：用于即时恢复，打开时与本机配置同步。文案、待上传素材、图片网址、API Key 与付费同意不保存为默认设置。

原功能说明保存在 `docs/听文原功能说明.md` 与 `docs/IndexTTS原功能说明.md`。音乐许可位于 `assets/music/LICENSES.md`，语音模型与依赖许可见 `tts/THIRD_PARTY_NOTICES.md`。

## 待制作队列与夜间制作（1.1.0）

短视频与长篇视频使用同一套队列。先整理稿件、选择音色、标题/字幕/音乐参数和照片，再点击“保存待制作项目”。书籍导入后，勾选要制作的章节并点击该书的“保存所选章节到队列”，每章形成独立项目；支持全部选中、全部取消与逐章选择。

保存时复制照片并固定参数，后续更改主界面配置不修改已保存项目。可使用本机照片、公开图片网址或当前任务已经生成并确认的图片；收费 AI 图片须先完成保存，不在无人值守的队列中临时要求 API Key 或付费确认。仅做 MP3 的草稿可以暂不选图，之后在队列中“添加 / 更换照片”。

打开“待制作队列 · 夜间制作”，调整顺序，点击“按顺序一键生成 MP4”。队列逐项执行语音合成、验证和 MP4 合成，使用已保存照片，不再要求逐项确认。也可点击“先按顺序生成 MP3”，完成后再点击生成 MP4，复用原音频。主工作区的“一键生成当前稿件 MP4”只运行刚保存的当前项目，不自动运行其他待制作项目。

“预约夜间开始”可选择未来日期和北京时间，并保存开始时间。服务在后台到时顺序制作，浏览器可以关闭；电脑需保持开机，不能手动关机或合盖。预约和制作期间防自动休眠，不承诺系统关机后的自动开机或唤醒。重启保存预约与项目；正在制作而中断的任务保留素材，需手动继续。

某项失败会保留原因与素材并继续下一项，支持单项重试。已完成项目不会自动重复生成。暂停、继续、停止及移出队列均保留已保存材料；移出只归档，不物理删除项目文件。队列运行时阻止另开同工作台生成任务，避免竞争；两个原软件仍保留各自的独立入口。

队列、项目配置和图片保存在 `queue/`，成品仍在 `jobs/<UUID>/`，当前项目和统一成品库都有 MP3/MP4 下载与定位入口。这些个人目录不上传 GitHub。

回归使用隔离的队列目录，避免读取或干扰用户夜间制作：

```sh
./.venv/bin/python -B scripts/run_tests.py
```
